# Contributing

1. Open an issue describing the proposed change and expected business outcome.
2. Work on a feature branch; avoid committing secrets or personal data.
3. Follow existing TypeScript, React and TanStack patterns.
4. Run `npm run lint` and `npm run build`; document any unavailable checks.
5. Include tests for security-sensitive or financial workflows.
6. Request review before merging to `main`. Never edit `src/routeTree.gen.ts` manually.

See [documentation](docs/README.md).
