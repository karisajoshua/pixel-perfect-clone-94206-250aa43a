# Engineering roadmap

## P0 — Security and operational confidence
- Inventory database policies, tenant boundaries and server authorization.
- Verify callback signatures, idempotency and reconciliation for IPEN/M-Pesa.
- Scan repository and history for accidentally committed secrets.
- Establish repeatable build, smoke tests and rollback procedure.

## P1 — Feature verification
- Test quotations, policies, claims, invoices, renewals and customer portal end to end.
- Validate DMVIC, WhatsApp, email and renewal automation in controlled environments.
- Verify AI assistant data access, privacy and guardrails.

## P2 — Documentation and developer experience
- Generate accurate API documentation from implemented handlers.
- Add an ERD after validating actual database schema.
- Add CI, onboarding examples, test fixtures and operational runbooks.
- Remove obsolete Lovable-facing metadata and consider a branded repository name.

All priorities are proposals; completion requires evidence from tests or source review.
